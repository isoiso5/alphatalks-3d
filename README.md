# Alphatalks3000 3D Renderer (Remotion + Three.js) — free via GitHub Actions

- 3D characters + 130 motion-capture animations: KayKit Character Animations by Kay Lousberg (CC0), downloaded at render time.
- Voice: Microsoft Azure neural voice via edge-tts (free) with exact word timing for captions.
- Music + sound effects are generated in `scripts/prepare.py` (soft piano, whooshes, booms, impacts).
- Long videos are split into up to 16 chunks that render in parallel, then stitched with ffmpeg.

## Start a render
POST /repos/<owner>/<repo>/actions/workflows/render.yml/dispatches
{ "ref": "main", "inputs": { "job_id": "render-123", "composition": "Story3D", "props": "file:stories/clarity-code.json" } }
`props` may also be a JSON string. The video + thumbnail appear as assets on the release tagged with job_id.

## Story format
See `src/types.ts` and `stories/clarity-code.json` (generated by `scripts/make_story.py`).
